A comprehensive Management System (ERP) for WordPress. Includes CRM, Accounting, HR, Helpdesk, and API.

== Description ==

Sahajanand ERP is a comprehensive management system for spiritual educational institutes and organizations. It provides a complete backend solution built on WordPress.

Features include:
* **Content Management**: Daily Darshan, Quotes, Updates, Satsang, and Programs
* **Calendar Events**: Manage scheduling and festival events
* **Accounting**: Track your finances seamlessly
* **CRM**: Comprehensive contact management
* **HR**: Manage human resources efficiently
* **Helpdesk**: Built-in support and ticketing system
* **Invoices and Expenses**: Keep track of payments and outgoing costs
* **Vouchers**: Manage entry and food passes

The plugin uses a modern React admin UI based on @wordpress/components and includes a robust REST API for integrating with mobile applications.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/sahajanand-erp` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Access the modules under "Sahajanand ERP" in the admin menu.

== Frequently Asked Questions ==

= Is there a mobile app available? =
Yes, the ERP system provides a comprehensive REST API that can be connected with custom mobile applications.
